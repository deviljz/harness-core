# 指标辅助视觉验收（试行v1，2026-11-07）

目标：帮助定位差异、比较候选及检查退步，不追求与原图完全一致，不用单个分数代替美术判断。本规则先冻结再跑实验，实验结论独立记录。

## 比较对象先分开

1. 素材保真：原图可见局部与新素材的同尺寸显示结果；报告已知背景/遮挡干扰。
2. 组装正确：已验收素材、布局和指定状态构成的预期结果与实际引擎输出。不能拿已经不同的素材去逼Unity逐像素对齐原图。

登记参考/候选哈希、实际尺寸、颜色空间、ROI（比较区域）、排除区域、状态/时间、指标参数和版本。不自动对候选旋转、缩放或平移找最高分。布局偏移单独检查，需要对齐诊断时额外报告变换和未对齐结果。

## 区域与证据

按唯一素材或有意义的局部比较；共用素材制作只计一次、组装检查各实例。不按背景面积加权成全页总分。允许把内部颜色、轮廓区分开，但在看分数前冻结定义，不能挪遮罩掩盖失败。

本轮排除文字/锁/数量及其阴影与抗锯齿范围；隐藏区域无法从截图核验，只检查补全合理性。原图轮廓或背景无法可靠分离时标注测量含背景，不伪称真值Alpha。SSIM使用完整局部窗口，排除与遮罩/图像边缘相交的窗口，不能将遮罩外两图填成相同颜色制造高分。有效像素/窗口太少则不计算该项。

输入使用明确背景上的不透明合成图；未合成的透明图拒绝直接按RGB比较。相同图像尺寸和明确data_range；记录sRGB显示值上的PSNR/SSIM，颜色项用明确的色差定义。不得混用不同分辨率、状态、随机特效相位。先保存干净/指定时刻截图再测。

## 初始指标组合

- PSNR：局部逐像素差异；越高越接近。不称百分比；相同图像记exact match而非伪造有限上限。
- 局部SSIM：局部明暗/结构辅助项；越高越接近，不等于人工还原评分。
- CIEDE2000色差：报告均值、中位数与方向性RGB差；越低越接近，不单凭均值决定调色。
- 边缘距离：辅助定位轮廓/高光位置问题，边缘不是自动分割的语义轮廓；参数冻结，不能据此自动识别箭头头数或按钮状态。
- 位置/尺寸、Alpha、独立层级、裁切、交互沿既有检查，不由上述指标替代。

初期不设置统一通过阈值、不合成总分、不接自动刷分循环。LPIPS等额外模型只有确有需要并经本项目验证后才引入。

## 小实验与决策

先记录肉眼判断，再评估旧版/当前版；另造有限的已知偏移、偏色、模糊对照，仅作为指标校准，不能混入生产素材。用同一参考的合成错误只证明敏感性，不证明对AI重绘的排序可靠。检查遮罩有效性以及指标之间是否矛盾，保留失败和不一致。

指标提示问题后，由AI结合实际尺寸的可见影响、改善把握、时间/token/调用成本和退步风险选择最值得的一项。修改前声明本轮假设、候选预算与停止条件，保留旧版；不得为追分自行扩大授权预算或持续搜索直到过线。

有实际可见改善且必要条件未退步才采用；分数上涨但看起来更差时拒绝。若修改无收益，保留原版也算完成一次有结论的实验，不能伪称画面提升。分数变化很小、主要来自纹理噪声/JPEG/抗锯齿、指标互相矛盾或下一次成功把握低时停止该项并记录理由。重大轮廓/状态错误仍需解决或明确待办，不能借边际收益标记通过。

## 交付

每项独立数值、有效覆盖范围、差异热图、实际尺寸前后对照、最早错误阶段、采用/拒绝与停止理由。优先本地计算，只有代表差异图进入模型上下文。规范完备、实验完成、视觉达标、用户确认分开。

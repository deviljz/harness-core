# 动态验收与回归

## 采样记录

- 以同一类触发作为零点，并记录毫秒。比较点击后的响应，用点击；比较入场、透明度等动画，用两端各自的展示挂载点。有结算或页面构建开销时同时记录点击到首帧。H5 可用真实点击、DOM mutation 或 rAF 标记，Unity 沿生产入口触发。确认录屏和测试等待没有改变实际时间。
- 一次性动效通常记录四个阶段。触发前的底图、开始可见、主体运动和落定。如果有跳字分段、延迟或跳过，再补对应采样。不同时间的截图只能作并排观察，不能证明同帧对齐。
- 连续证据要能复查。录像或高密度时序图适合看抖动、重叠、淡入、尾迹和销毁。点按后的输入可用性、真实状态变化和复位用断言辅助。同尺寸并排，尤其关注短屏遮挡与原始画面初始位置。标明未触发、未采到和仅代码核对的效果。
- 网页常规动效采样显式设 `reducedMotion: 'no-preference'`，把 `matchMedia` 实测结果存入证据，再单开 `reduce` 对照关键路径。宿主系统的动画开关可能改变默认值。扫光、遮罩等伪元素同时检查 `content`、`display` 和实际动画轨道，样式里声明了 `animation-name` 也可能完全没有绘制。

## 经常漏掉的检查

| 问题 | 提前核对 | 验收 |
| --- | --- | --- |
| 动画在最终截图里看似正确，实际上瞬间完成 | 触发前后和中段都采。查时间源，查看是否用帧数或速度快照驱动画面 | 至少观察到过渡和落定，在不同帧率用真实时间保持节奏，结束后主操作可用 |
| 整屏帧率正常，单位或跳字仍有停顿感 | 同时量整屏帧耗时和单位、世界位移、跳字各自的可见更新间隔。图集按原动作周期数相邻不同的姿势。录屏要用时间戳，并用静止区域估计压缩误差 | 地图位移和跳字使用连续的表现时钟，单位动作节奏与源端一致。标明图集采样、后台画面包或实际渲染帧分别造成的限制 |
| 只有局部在动，整张主体却随序列帧闪烁或占用大量贴图 | 沿真实入口确认谁在切帧。比较未压缩源帧，找出始终相同的主体和变化边界，区分整图序列、静态分段背景及单张兜底。源帧里的固定像素在成品里跳变时，核对实际压缩格式和每格的压缩块对齐 | 主体用固定图，局部动效共用裁片和时钟。保留原混合方式及减少动画兜底，两套界面分别录满一个以上循环。固定区稳定，局部仍动。分别记录实际 GPU 贴图字节和同配置前后 APK 大小 |
| 升级、资源或战斗跳字从屏幕固定点出现 | 选不同卡片、对象和站位触发，记录坐标所属层 | 跟随实际肖像或世界对象，缩放、相机移动、取消后位置和销毁正确 |
| 静态资源或表现用错，层级实际有误 | 查正在渲染的 src、CSS 背景、Canvas asset 和图集帧，复用原图。查父子层级与叠放顺序，截下实际重叠处。等比缩放素材还要查图框内的居中方式和镜像轴 | 图框和实际画出来的内容都对齐。底图、徽章、横幅的遮挡关系一致，光效或遮罩不吞文字和点击 |
| 自动转换看起来像旧 Unity 界面，网页装饰变成占位符 | 记录生成区域的父容器尺寸与锚点来源，查是否直接套用旧界面的外框。检查 CSS 伪元素与没有正文的子节点，例如阶位点，给不同数量的状态各取样 | 两种视口并排核对生成区域的定位与装饰，短屏主控件可用。过渡交给原生表现时，比较交接前后的位置。对未转换区块和占位符明确标注 |
| 首屏控件尺寸数据正确，实图的底色、轮廓或小图标仍有偏差 | 等网页主题切换和有限时 CSS 过渡结束再取静态样式。分开查透明点击框和实际可见图层。阶位点等小标记同时量实心、外描边和旋转后边界，状态图标追到当前页面实际使用的资源 | 用稳定实图比较填色范围、边界和图形。节点数量、点击范围及资源文件存在性只验证各自一项 |
| 同存档的动作对照里，单位类型或格子位置仍然不一致 | 两端沿真实操作触发，留存动作前后的可见状态，例如棋盘坐标、兵种和阶位。截图记录实际采样时刻 | 先核对终态数据，再对照同时间段的表现。避免把不同批次的截图当成同一次动作 |
| 宝箱、采集物或奖励跟着屏幕走 | 让相机有可见位移，比相邻帧相对地面的位置 | 地图对象跟着地图，界面提示跟着界面。奖励飞入独立走它原来的路径 |
| 文字细节与布局逐页漂移 | 检查实际字体、盒子、字效、对齐和字体 fallback。网页可用浏览器开发者工具查看实际用到的字形及字重，Unity 查实际字体和是否又额外加粗。用长数字及图文在窄屏复测 | 数字完整单行，图标与文字视觉上同一行，标题粗细与参考实图一致。明确要求居中的按钮居中，共用栏一致 |
| 弹窗模糊重建、临时特效吞输入或关不掉 | 查第一次打开、关闭、重复开、换页和短屏的捕获与销毁 | 冻结背景时只捕获必要次数，动画无额外射线拦截，流程可点击、可离开、可重开 |
| 动效带来多次奖励或更改逻辑节奏 | 用相同存档跑正常、跳过和重复点击 | 单次结算；视觉动画与规则相互独立，奖励和存档遵守原规则 |
